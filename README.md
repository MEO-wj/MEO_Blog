# Blog Migration Pack

这个目录是给后续拆分博客仓库准备的搬运包，已经把你目前最可能要带走的内容集中复制到一起。

## 内容结构

- `blog-docs/`
  - 旧版博客方向 `README.md`
  - 旧版博客方向 `concept-design.md`
  - 原参考图 `参考图.jpg`
- `model-docs/`
  - `docs/model-sourcing-guide.md` 的副本
  - `public/models/README.md` 的副本
  - `external-assets/README.md` 的副本
- `model-assets/`
  - `public/models/` 的完整副本
  - `external-assets/` 的完整副本

## 原始来源

- 旧博客说明文档来自当前仓库 `HEAD` 版本中的：
  - `README.md`
  - `docs/concept-design.md`
- 找模型相关说明文档来自：
  - `docs/model-sourcing-guide.md`
  - `public/models/README.md`
  - `external-assets/README.md`
- 模型资源来自：
  - `public/models/`
  - `external-assets/`

你后面如果要新建博客仓库，可以直接把这个目录里的内容按需剪切出去。
