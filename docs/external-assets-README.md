# External Assets

这个目录是布局编辑器的外部资产暂存区。

它用于承接还没有正式进入编辑器资产库的内容，包括：

- 第三方下载模型
- AI 生成模型
- 自己导出的原始模型
- 处理中间产物
- 来源和授权记录

## 目录职责

### `raw/`

放原始文件，尽量保持接近来源包的结构。

### `processed/`

放已经清洗过、但还没正式发布到 `public/models/` 的版本。

### `licenses/`

放来源链接、授权信息、记录截图和备注。

## 推荐流程

1. 先把外部模型放进 `raw/`
2. 记录来源和授权
3. 清洗、拆分、减面、统一命名
4. 将中间结果放入 `processed/`
5. 只有确认可稳定用于编辑器后，才复制到 `public/models/`

## 说明

这个目录是资产生产线的一部分，不是最终运行时资源目录。

如果一个模型还只存在于这里，就说明它还处在：

- 待检查
- 待清洗
- 待确认授权
- 待进入正式模型库

的阶段。
