> 基于 3D 游戏主机场景叙事设计的个人博客网站

---

## 一、产品概述

MEO Blog 是一个以 **3D 游戏主机场景** 为核心交互入口的个人博客网站。访客进入网站后，首先进入一个可探索的 3D 虚拟房间，房间内摆放着 Nintendo Switch、PlayStation 5、游戏手柄、卡带、收藏品和科幻风格书桌。点击 Switch 屏幕后，镜头以电影级动画推进，进入一个完整的 **Nintendo Switch 风格主界面**，所有博客内容均通过该界面进行导航和展示。

**设计理念**: "以 3D 为入口，以 2D 页面承载内容阅读"

---

## 二、核心特色

### 2.1 沉浸式 3D 场景

网站首页并非传统的 2D 页面，而是一个完整的 Three.js 3D 场景：

- **夜间房间环境**: 深色调背景搭配星空雾气，营造沉浸式氛围
- **科幻风格桌面**: 带网格地板、墙壁和氛围灯光
- **丰富模型资产**: PS5 主机、DualSense 手柄、Switch 掌机、底座套装、游戏卡带、食人花收藏品、沙发、储物柜等
- **动态光照**: 方向光（月光）+ 脉冲点光（桌面屏幕辉光）+ 暖色边缘光 + 蓝色填充光，支持 2048x2048 阴影贴图
- **自由视角**: 支持 OrbitControls 轨道控制，可旋转、缩放探索整个房间
- **镜头动画**: 从全景视角到 Switch 屏幕的电影级推拉动画，平滑插值过渡

### 2.2 Switch 风格主界面

进入 Switch 屏幕后，呈现一个 1280x720 分辨率的主机风格 UI：

- **顶栏**: 用户头像、昵称、邮箱、北京时间实时时钟
- **项目卡片栏**: 水平滚动的项目展示区，支持拖拽滚动和键盘导航
- **底部功能栏**: 7 个功能按钮，模拟主机手柄操作体验
- **完整键盘导航**: 方向键切换项目/功能区，Enter 确认，G 打开 GitHub，Escape 返回 3D 场景
- **音效系统**: 5 种 Switch 风格音效（悬停、点击、关闭等），40% 音量，防抖播放

### 2.3 手机端适配

在移动设备上提供优化的轻量体验：

- **自动分流**: 视口 ≤ 760px 时自动切换为 2D Nintendo App 风格布局
- **零 3D 依赖**: 不加载 Three.js 和 GLB 模型，节省流量，提升首屏速度
- **完整功能**: 项目展示、GitHub、简历、留言墙、博客阅读均可使用
- **独立博客入口**: 手机端专属博客浏览，支持分类简介展开/收起

## 三、功能模块

### 3.1 项目展示

- 项目卡片展示：图标、标题、副标题、分类标签、主题色
- 项目详情弹窗：Markdown 渲染的项目简介、技术栈图标、状态徽章
- GitHub 仓库快速跳转
- 按需加载：首页仅加载摘要数据，点击后懒加载完整详情
- 骨架屏加载动画

### 3.2 博客系统（魔法书架）

以 **魔法书架** 为主题的博客阅读体验：

- **书架视图**: 分类以 3D 书本形式展示在书架上，每本书有自定义图标、颜色和文章计数
- **卷轴视图**: 文章以羊皮纸卷轴样式呈现，支持标题、摘要、日期和草稿标记
- **阅读器**: 羊皮纸风格内容区，支持 GFM Markdown 渲染（表格、删除线等），带装饰性边框
- **评论系统**: 昵称 + 邮箱 + 内容，管理员可删除任意评论
- **管理功能**: 分类和文章的增删改查，支持草稿/发布状态切换

### 3.3 留言墙（留言板）

社区互动留言系统：

- 发帖：昵称（本地缓存，回访自动填充）+ 内容（500 字限制）
- 回复：支持多层回复，管理员回复有专属徽章和样式
- 审核机制：管理员可在后台审核留言，审核通过后公开可见，拒绝后仅作者自己可见
- 删除：用户可删除自己的留言和回复，管理员可删除任意留言和回复
- 时间显示：相对时间格式（"刚刚"、"X 分钟前"、"X 天前"）
- 头像：首字母头像或上传图片
- 快捷操作：Enter 发送，Shift+Enter 换行

### 3.4 收藏展示（任务布告栏）

以 **奇幻任务布告栏** 为主题的收藏展示系统：

- **布局算法**: 基于 Knuth 乘法哈希的确定性伪随机布局，卡片旋转、宽度、高度均自动计算
- **视觉元素**: 铁钉固定、羊皮纸背景、火漆印章装饰
- **灯箱查看**: 点击图片可全屏查看
- **管理功能**: 图片上传、拖拽重新排列、删除

### 3.5 简历展示

- 简历以图片形式展示
- 管理员可上传/替换简历图片
- 加载状态动画和错误重试机制

### 3.6 GitHub 集成

通过后端代理解决 CORS 问题，展示 GitHub 数据：

- **个人资料**: 头像、昵称、简介、位置、邮箱、关注者/关注数
- **贡献热力图**: 最近 90 天贡献记录，GitHub 绿色系配色，动画入场
- **公开仓库**: 名称、描述、语言、Star 数、Fork 数、最后更新时间
- **数据融合**: GitHub 缺少的信息自动从管理员资料补充

### 3.7 管理后台

以 **终端窗口** 风格呈现的管理面板：

**登录机制（双重验证）**:
- 密码输入 + 手柄按键序列（方向键 + ABXY 组合）
- 模拟 "你知道的 + 你能做的" 双因素认证

**管理功能**:
- **个人资料编辑**: 头像上传、昵称、邮箱、手机、省市、GitHub URL、简介
- **项目管理**: 拖拽排序、创建/编辑/删除项目、图标上传、Markdown 简介、技术栈选择（700+ 技术图标）
- **博客管理**: 分类 CRUD、文章 CRUD、评论删除
- **留言管理**: 审核留言（通过/拒绝）、管理员回复、删除留言和回复
- **收藏管理**: 图片上传、拖拽排序、删除
- **合作伙伴管理**: 图标上传、链接编辑、排序、删除
- **入口权限管理**: 配置游客是否可见 3D 场景入口

### 3.8 手机端适配

视口宽度 ≤ 760px 时自动切换为轻量 2D App 布局，不加载 Three.js / GLB 模型：

- **Nintendo App 风格首页**: 方形项目图标横向滑动 + "我的空间"快捷入口
- **底部导航栏**: GitHub / 简历 / 留言，模拟主机 Dock 操作体验
- **博客阅读器**: 独立手机端博客浏览，分类简介过长时支持展开/收起
- **性能优化**: 零 3D 依赖，首屏加载速度快，节省移动流量

### 3.9 合作伙伴

展示友情链接与合作方：

- 横向滑动展示合作伙伴图标
- 点击跳转外部链接
- 管理员可增删改排序

### 3.10 游客入口权限

灵活控制站点访问权限：

- 管理员可配置是否对游客开放 3D 场景入口
- 关闭入口时，游客看到友好提示页面而非空白
- 手机端同步受权限控制

### 4、设计理念

MEO Blog 不是一个传统的博客模板，而是一个 **以叙事驱动的交互体验**：

1. **3D 场景作为叙事入口**: 访客不是看到一个列表，而是 "走进" 一个游戏房间
2. **主机 UI 作为导航中枢**: Switch 风格界面将博客功能游戏化，降低阅读门槛
3. **主题化内容呈现**: 博客是魔法书架、收藏是任务布告栏、管理后台是终端窗口
4. **音效增强反馈**: 每一次交互都有主机风格的音效反馈
5. **暗色沉浸氛围**: 深色调 + 氛围灯光 + 3D 阴影，营造夜间游戏房的沉浸感

**目标**: 让访客在浏览个人博客时，获得类似打开游戏主机的仪式感和探索乐趣。
